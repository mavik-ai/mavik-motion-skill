# Cinemática editorial — Storytelling e transições

## Uma ideia por cartela

- Narrativa: frase falada → decisão visual → movimento → próxima frase.
- Não reproduzir todas as palavras em tela. Destacar 2–7 palavras-chave por cartela.
- A mudança de cartela deve ser motivada por uma mudança semântica ou musical.
- Alternar enquadramentos abertos, macro tipografia, composições recortadas e formas para evitar monotonia.

## Bibliotecas de transições (princípios)

| Técnica | Entrada | Saída | Cuidado |
|---|---|---|---|
| Match cut de texto | Palavra central | Palavra vira máscara ou eixo da próxima cena | A leitura não deve quebrar |
| Slide continuity | Cartela entra lateralmente | Mesmo vetor conduz novo elemento | Não criar efeito PowerPoint |
| Scale bridge | Objeto cresce | Virada de escala revela próximo plano | Evitar zoom agressivo em todo corte |
| Graphic match | Forma vira contorno | Contorno recontextualiza a próxima mensagem | Respeitar coerência visual |
| Wipe motivado | Linha/coluna/cor cobre frame | Revela a próxima cartela | Não usar wipe arbitrário |
| Tempo de pausa | Movimento estabiliza | Sustenta palavra ou CTA | Necessário para compreensão |

## Planejar uma cena

Campos obrigatórios: `start`, `end`, `title`, `voiceover`, `visual`, `transition`.

1. Qual é a mensagem? (não o efeito)
2. Qual objeto ou palavra materializa essa mensagem?
3. O que o objeto vira depois? Especificar objeto → movimento → resultado.
4. Em qual sílaba/palavra e beat ocorrem as ações?
5. O espectador consegue ler em uma tela de celular?

## Critérios anti-slideshow

Se cada nova cena apenas fizer `fade out -> fade in`, refazer as transições. Usar continuidade de posição, direção, forma, escala ou assunto. Não criar links artificiais quando um corte seco bem motivado for mais claro.
